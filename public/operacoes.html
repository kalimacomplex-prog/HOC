Auditoria de Configuração
Os campos cadastrados aqui (ex.: login, senha, api_key — o nome é livre) nunca precisam ser digitados diretamente no código do robô. Ao rodar pelo Agent HOC, o robô recebe automaticamente as credenciais de acesso (HOC_ROBOT_KEY) como variável de ambiente — o script só precisa solicitar a credencial pelo nome: 
import os, requests

SERVER = os.environ.get('HOC_SERVER')
HEADERS = {'x-robot-key': os.environ.get('HOC_ROBOT_KEY', '')}

r = requests.get(f"{SERVER}/api/credenciais/<nome_da_credencial>/valor", headers=HEADERS)
campos = r.json().get('campos', {})
login = campos.get('login', '')
senha = campos.get('senha', '')
Substitua <nome_da_credencial> pelo nome exato cadastrado na tabela abaixo. No framework OOP (HocRobot), o mesmo resultado sai com uma linha: self.credencial('nome').

Download do Agent por Máquina
Cadastre uma máquina em Ambiente para gerar o pacote do Agent.
Como utilizar
O Agent é um script Python que você instala em cada máquina. Ele recebe ordens do SaaS, executa robôs e envia heartbeats a cada 20s.
1
Criar Máquina
Cadastre a máquina em Ambiente — o SaaS gera uma chave secreta única
2
Baixar Agent
Clique em Baixar Agent na máquina desejada — gera agent.py + config.json
3
Instalar e Rodar
Dê duplo clique em iniciar.vbs — instala tudo (Python, dependências) e sobe o Agent sozinho, sem janela
4
Máquina Online
Em até 20s a máquina aparece Online em Ambiente e já pode executar robôs
Ícone do Agent na bandeja do Windows
Enquanto o Agent está rodando, aparece um ícone redondo perto do relógio do Windows (canto inferior direito). Se não aparecer ali direto, procure no "^" (seta de ícones ocultos) — é comum o Windows esconder ícones novos lá.
Verde — conectado normalmente ao HOC
Vermelho — com problema (sem rede, ou chave inválida)
Cinza — iniciando, aguarde alguns segundos
Clique com o botão direito no ícone para abrir o menu:
  • Uma linha mostrando o nome da máquina e outra com o motivo do status atual (ex: "Conectado ao HOC", "Sem conexão com o servidor", "Chave inválida...")
  • Reiniciar Agent — reinicia o processo na hora, sem precisar baixar/instalar nada de novo
  • Ver logs — abre o arquivo agent.log (histórico completo do que o Agent fez)
  • Sair — encerra o Agent (a máquina fica Offline até rodar de novo)
O que fazer se a máquina ficar Offline
Acontece automaticamente se o SaaS não recebe heartbeat por mais de 90 segundos.
1. Olhar o ícone do Agent na bandeja do Windows
Perto do relógio: verde = conectado, vermelho = com problema (clique com o botão direito pra ver o motivo).
Não achou o ícone? O Agent não está rodando — dê duplo clique em iniciar.vbs de novo.
Reiniciar: clique direito no ícone → Reiniciar Agent (não precisa reinstalar nada).
2. Verificar conectividade
A máquina precisa alcançar o endereço do servidor configurado em config.json (campo server) pela rede local ou internet.
Se o ícone estiver vermelho com "Sem conexão com o servidor", verifique Wi-Fi/cabo e se não há firewall/VPN bloqueando essa porta.
3. Validar config.json
Abra config.json e confirme que:
• server aponta para a URL correta
• machineKey não está em branco
• machineId corresponde ao ID cadastrado aqui no SaaS
Se precisar, re-baixe o Agent nesta tela.
4. Verificar o arquivo de log
O Agent roda escondido (sem janela), mas grava tudo em agent.log, na mesma pasta do agent.py.
Pelo ícone da bandeja: clique direito → Ver logs abre esse arquivo direto.
ModuleNotFoundError → falta instalar dependência, rode pip install requests psutil pystray pillow
5. Máquina desligou ou reiniciou
Se você instalou pelo iniciar.vbs, o Agent já sobe sozinho a cada login (ele mesmo cria essa tarefa no Agendador do Windows) — não precisa fazer nada.
Se ainda assim não voltar, dê duplo clique em iniciar.vbs de novo.
6. Máquina em Manutenção
Se você colocou a máquina em modo Manutenção no painel de Ambiente, ela não recebe novos comandos.
Para reativar, clique no toggle Manutenção novamente na lista de máquinas.

Método Endpoint Descrição
POST/api/maquinas/heartbeatAgent envia status (CPU/RAM) e recebe comandos pendentes
POST/api/robos/execucoes/:id/logsRobô envia log com status (info / success / error)
GET/api/robos/execucoes/:id/statusAgent verifica se execução foi interrompida
GET/api/credenciais/:nome/valorRobô busca credencial pelo nome (retorna JSON)
POST/api/robos/execucoes/:id/artifactsRobô faz upload de arquivo gerado (PDF, Excel...)
